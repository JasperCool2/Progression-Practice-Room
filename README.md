# Progressie Oefenkamer

Oefen de meest voorkomende akkoordprogressies in jazz, pop en klassiek. De app kiest automatisch Nederlands of Engels; wisselen kan met de NL/EN-knop rechtsboven.

Practise the most common chord progressions in jazz, pop and classical. The app picks Dutch or English automatically; switch with the NL/EN button at the top right.

**Installeren / Install:** open de GitHub Pages-link in Chrome en kies *App installeren* (Android) of *Delen → Zet op beginscherm* (iPhone).

**Nieuwe versie / Update:** verhoog `VERSION` bovenin `sw.js` (bijv. `po-app-v2`).
